# Christopher Grantham — Portfolio

Personal portfolio for Christopher Grantham, a sales leader, web designer, coder, and AI-agent-powered builder based in Newport, Washington.

Live site: the Vercel production URL for project `chris-grantham-portfolio` (custom domain `christopher-grantham.com` once DNS is pointed).

## Structure

- `index.html` — hero, live-demo workspace, about/resume, contact
- `styles.css` — mobile-first navy/blue layout
- `app.js` — demo sidebar, iframe embeds, and screenshot fallbacks
- `assets/Christopher_Grantham_Resume_v2.pdf` — public resume (email, LinkedIn, and city only)
- `assets/demos/` — screenshots for sites that block embedding

## Local preview

Open `index.html` in a browser, or run any static server from this folder.
